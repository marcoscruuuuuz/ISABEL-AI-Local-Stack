# Frota de Agentes Locais ISABEL (até 100)

## Uso no chat
```
AGENTE-PC-financeiro01 quantos R$ foram lançados hoje no sistema deste computador?
```

## Cadastro (Admin)
1. Admin → Frota → Novo Agente
2. Nome: AGENTE-PC-financeiro01
3. Sistemas locais JSON
4. Gera install_key
5. No Windows: claim_and_install.ps1 -InstallKey XXXX
6. Agente ONLINE e responde no chat

## Segurança
Um token por agente · Sem porta de entrada · Allowlist · Isolamento por tenant
